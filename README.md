# AnyCompresssionThatMayWork

一个轻量的 Windows 压缩 / 解压工具。目标很简单：不装一堆运行时、不往 C 盘塞东西、关掉就走。

## 特性

- 压缩 / 解压 `zip`、`tar`、`gz`、`tgz`
- 拖拽文件即可开始，支持批量
- 原生 Rust 核心，无外部运行时依赖
- 全部本地处理，不联网
- 关闭窗口时后台进程一并退出，不留残留

## 三个版本

| 版本 | 文件 | 体积 | 说明 |
| --- | --- | --- | --- |
| Rust 绿色版 | `green.zip` | 2.2 MB | 解压即用，不写 C 盘 |
| Rust 安装版 | `setup.exe` | 2.3 MB | 可选加入“打开方式”，一键卸载 |
| Electron 绿色版 | `electron-green.zip` | 151.8 MB | 旧版外壳，兼容备用 |

## 使用

从 [Releases](../../releases) 下载对应版本：

- **绿色版**：解压到任意文件夹，运行 `AnythingThatMayWork.exe`。所有数据（配置、解压输出）都写在 exe 同级的 `data/` 目录，删除整个文件夹即彻底移除。
- **安装版**：运行安装程序，按向导完成。在设置里可开启“在打开方式中显示”，卸载时会清除注册表关联与全部数据。

## 说明

- “打开方式”默认**关闭**，不会抢占系统默认程序；需要时在设置中手动启用，或点“去系统设置设为默认应用”。
- 绿色版不会在 `%LOCALAPPDATA%` / `%APPDATA%` 创建任何目录。
